# JCB Demo Eshop

Clothing Store demonstration built with Joomla Component Builder 6.2.1-alpha2 for Joomla 6.2.0 and PHP 8.4.

The editable component root is `44341802-d820-5677-bfc4-14b390b4da3b`. The component source graph is intended to be published through JCB's Packages Push, with the fourteen project-owned Super Powers published through their separate Power export. An initial documentation commit alone is not the blueprint and must not be treated as a completed source export.

The application includes a responsive catalogue, normalized product variants, server-side carts and inventory reservations, expert separate-table variant editing, immediate CSV/XLSX importing through the shared Import.Transient Powers, immutable order snapshots, and sandbox-only PayPal integration. Fresh installation seeds eight products and sixty variants.

This is a demonstration, not a production-verified commerce service. Real sandbox payment delivery, the complete authenticated API-role matrix and true overlapping checkout concurrency remain unverified. Parent metadata and child inventory use an explicitly documented two-phase save; only the child batch is atomic.

No credentials, customer account exports, full-site backups or local database dumps belong in this repository. Read source dependencies, exact tested revisions and installation/rebuild instructions in the completed delivery receipt before attempting reconstruction. JCB Packages, Super Powers and installation ZIPs are distinct deliverables.
